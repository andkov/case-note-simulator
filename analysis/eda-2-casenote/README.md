# EDA-2 Case Note Analysis

Three-layer analytical framework for synthetic social services case notes, designed to support risk stratification, individual case flagging, and contextual interpretation.

## Overview

This analysis system implements a comprehensive approach to case note analysis through three integrated layers:

1. **Layer 1 - Demographics**: Population profiling and risk stratification
2. **Layer 2 - Individual Analysis**: Case-level risk flagging and sentiment analysis
3. **Layer 3 - Contextual Interpretation**: Reference group comparisons and benchmarking

## Analytical Layers

### Layer 1: Demographics
- Age, gender, location distributions
- Complexity level stratification
- Risk profile characterization
- Population baseline establishment

### Layer 2: Individual Analysis
- **Basic Text Features**: Note length, word count, writing style indicators
- **Risk Flag Detection**: Substance use, housing crisis, mental health, family separation
- **Sentiment Analysis**: Via Python transformers models
- **Urgency Scoring**: Composite risk assessment (0-1 scale)

### Layer 3: Contextual Interpretation
- **Overall Baseline**: Population-wide risk indicator rates
- **Complexity Cohorts**: Within-group comparisons by case complexity
- **Geographic Context**: Regional patterns and service environment factors
- **Benchmarking Framework**: Individual case positioning within reference groups

## Risk Flagging System

The system identifies key risk indicators through pattern matching and NLP analysis:

- **Substance Use**: Alcohol, drugs, addiction terminology
- **Housing Crisis**: Eviction, homelessness, housing instability
- **Mental Health**: Depression, anxiety, suicidal ideation
- **Crisis Indicators**: Emergency language, urgent intervention needs
- **Family Separation**: Child custody, placement with relatives

## Visualization Components

- **Demographic Plots**: Age distributions, complexity by location
- **Risk Flag Analysis**: Prevalence rates across population segments
- **Contextual Dashboards**: Individual case positioning within reference groups
- **Trend Analysis**: Temporal patterns in risk indicators

## Troubleshooting

### Common Issues

**File Not Found Error**:
```r
# Error: cannot open file './data-public/derived/synthetic-case-notes-for-input.csv'
# Solution: Update input_file path in eda-2-dashboard.R (line 27)
input_file <- "./abc/take-2/output/synthetic-case-notes-for-input.csv"
```

**Missing Packages**:
```r
# Install required packages:
install.packages(c("tidyverse", "ggplot2", "patchwork", "scales", "lubridate"))
```

**Dashboard Generation Fails**:
- Check that `prints/` directory exists (created automatically)
- Verify input data file path is correct
- Ensure all required packages are installed

**Labels Cut Off**:
- Increase `dashboard_height` for more vertical space
- Adjust `expansion(mult = c(0, 0.15))` for more label padding
- Reduce font sizes if text doesn't fit

**Memory Issues**:
- Large datasets may require more RAM
- Use `rm()` to clear unused objects
- Restart R session if needed

### Quick Fixes
